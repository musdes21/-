# زاد (Zad)

تطبيق عربي لإدارة مصاريف المغترب: ميزانية شهرية، تحويل التوفير، خطة أكل أسبوعية، وقائمة تسوّق.

## الملفات
- `app/index.html`: التطبيق كاملًا (HTML و CSS و JavaScript في ملف واحد، بدون خادم).

## التشغيل
افتح `app/index.html` في المتصفح. البيانات تُحفظ في `localStorage` لذلك المتصفح.

## ملاحظات
- الباقات المدفوعة معاينة فقط، ما فيه دفع حقيقي.
- الأسعار في الوجبات والتسوّق تقديرية.
